## Notes

- After generating service images, drop into `public/images/services-og/{slug}.png`.
- After generating hire page images, drop into `public/images/hire-{slug}.png`.
- Once an image is placed and confirmed, move it to the "Already Generated" table above and remove the prompt.
- If Midjourney adds text incorrectly, regenerate without the text parts and add text in Canva/Figma.
- Use the same generation session so colors stay coherent across all banners.
- Consistent style tip: seed the same `--seed` value across all banners for visual coherence.
