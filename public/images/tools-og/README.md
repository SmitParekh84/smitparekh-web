# OG Image Generation Prompts — Free Tools Pages

Generate each image at **1200 × 630 px**, export as **PNG**.
Save with the filename shown — that's the path the sitemap and metadata will reference.

---

## Brand Style Guide

| Property | Value |
|---|---|
| Background | `#05050f` (near-black, very dark navy) |
| Primary accent | `#0628FF` (electric blue) |
| Secondary accent | `#00C5EC` (cyan) |
| Text color | `#ffffff` |
| Mood | Minimal, dark, single-focus, no gradients on elements |
| Font feel | Geometric sans-serif (Geist, Inter, or similar) |
| Avoid | Photos, people, gradients on background, clutter, shadows |

Use these prompts in **Midjourney**, **DALL-E 3**, **Adobe Firefly**, or **Canva AI**.

## After Generating

1. Place each file in `smitparekh-web/public/images/tools-og/`
2. Add the entry to `toolOgImageMap` in `data/tools-seo.ts`:
   ```ts
   "youtube-thumbnail-downloader": "/images/tools-og/smit-parekh-youtube-thumbnail-downloader-tool.png",
   "json-formatter": "/images/tools-og/smit-parekh-json-formatter-tool.png",
   "base64-encoder-decoder": "/images/tools-og/smit-parekh-base64-encoder-decoder-tool.png",
   ```
   The sitemap and page metadata both read from this map automatically — no other files to touch.
